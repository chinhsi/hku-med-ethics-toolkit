# 繁中與簡中語句例

改編自原 MIT hku-consent-form 中文語句庫。以下是用語例，不是研究事實或官方批准。現行 MEd 規則優先，不從例句猜風險、保存期或程序。

| 用途 | 繁中 | 簡中 |
|---|---|---|
| 學生研究者 | 本人就讀香港大學教育學院[課程]，導師為[姓名]，邀請您考慮參與下述研究。 | 本人就读香港大学教育学院[课程]，导师为[姓名]，邀请您考虑参与下述研究。 |
| 校長許可 | 擬申請貴校准許下述活動。學校許可不代替個別參與者同意或學生本人的同意。 | 拟申请贵校准许下述活动。学校许可不代替个别参与者同意或学生本人的同意。 |
| 家長 | 邀請　貴子弟參與下述活動。子弟本人可選擇不參加。 | 邀请您的孩子参与下述活动。孩子本人可选择不参加。 |
| 兒童 | 你可以說不。你可以叫我們停下來。 | 你可以说不。你可以叫我们停下来。 |
| 自願 | 參與自願，可拒答或停止。[說清保障及資料撤回方式與期限。] | 参与自愿，可拒答或停止。[说清保障及数据撤回方式与期限。] |
| 錄音 | 只有另行同意才開始錄音。[說明不同意時的安排。] 保存期間可檢視並要求刪除部分或全部錄音。[實際聯絡及時間安排。] | 只有另行同意才开始录音。[说明不同意时的安排。] 保存期间可查看并要求删除部分或全部录音。[实际联系及时间安排。] |
| 保密 | 報告用假名，刪除或概括可識別細節。研究者知道您的身份，因此收集時屬保密，並非匿名。[存取／儲存／對照表／保存。] 保密受適用法律的披露義務限制。[額外保障。] | 报告用化名，删除或概括可识别细节。研究者知道您的身份，因此收集时属保密，并非匿名。[访问／存储／对照表／保存。] 保密受适用法律的披露义务限制。[额外保障。] |

香港研究每份文件列導師姓名、電郵及可聯絡電話，不能以學生電話代替。香港研究操守委員會正式繁中名稱為「香港大學研究操守委員會」，簡中為「香港大学研究操守委员会」；聯絡 hrec@hku.hk、+852 3917 5267。
